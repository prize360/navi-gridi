# Гриди — пилот

Гриди собирает страницу из текста по сценарию и шаблонам. Нави — гайд и прототип навигации. Страницы, ключ модели и правки библиотеки хранятся в браузере пользователя.

## Как работать

- **Страница** — «Создать страницу» или пример. Вкладки: Текст · Шаблоны · Превью · Проверка.
- **Модель** — вручную (копировать промт в свою модель) или свой ключ (адрес в формате OpenAI API). Ключ хранится только в браузере.
- **Поделиться макетом** — меню выгрузки → «Скачать архив страницы». Макет выглядит как у автора; шаблоны автора, которых у коллеги нет, сохраняются только для этого макета и в его библиотеку не попадают.
- **Итоги пилота** — «Настройки → Итоги пилота»: архив с правками библиотеки, недостающими шаблонами, составом страниц и запусками модели.
