# Стандарт промтов Гриди

Все промты Гриди — системные и прогоны коллег — собраны из одних разделов в одном порядке. Модель читает их одинаково, а человек быстро находит, что поменять.

| Раздел | Что в нём | Обязателен |
| --- | --- | --- |
| ЗАДАЧА | Кто модель, какой это этап, что сделать — 1–3 строки | да |
| ВХОД | Что придёт и в каком виде (строки с номерами, блоки с полями) | да |
| ТЕКСТ | Что можно менять в тексте, а что нельзя | да |
| ПРАВИЛА | Короткий список, только про эту задачу | да |
| ОТВЕТ | Схема JSON и общие правила формата | да |
| ПРИМЕР | Вход и правильный ответ | нет |
| УТОЧНЕНИЯ СЦЕНАРИЯ | `{{правила}}` из сценария | если сценарий их даёт |
| ДАННЫЕ | Текст или блоки — всегда последними | да |

## Общие правила формата (раздел ОТВЕТ, дословно во всех промтах)

- Только JSON одним блоком кода ```json, без пояснений.
- Номера строк — строкой: "5", "6-8", "6,9".
- Массивы — массивами, не строкой с JSON внутри.
- Нет значения — "" или [].
- Только поля из схемы: других ключей и типов не добавляй.

## Правила сценария

Правила сценария (`rules` в `library/scenarios.js` или «Особые правила разбора» в библиотеке) попадают в раздел УТОЧНЕНИЯ СЦЕНАРИЯ. Они уточняют задачу, но формат ответа не меняют. Пишите их в терминах ответа своего промта:

| Тип сценария | Промт | Термины |
| --- | --- | --- |
| Статья | «Разбор статьи» | типы head, text, short, list, quote, number, table, faq, cta, image, skip; поля h, paras, items, author, button |
| Лендинг (мероприятие, продукт, курс, промо) | «Разбор лендинга» | слоты сценария; поля title, lead, paras, meta, items, images, cta |

Правило в чужом формате модель может выполнить вместо основного: 19.10 сценарий «Статья» содержал правила в формате content/vrez, и GigaChat отвечал по ним. Редактор сценария подсвечивает такие слова (`G.rulesLint`).

## Как добавить свой промт

1. Скопируйте «Редполитика» или «Интеграция» в библиотеке.
2. Меняйте ЗАДАЧА, ТЕКСТ и ПРАВИЛА. ОТВЕТ и ДАННЫЕ не трогайте — по ним Гриди читает ответ.
3. Проверьте на одной странице вручную, потом отдайте коллегам.

## После обновления библиотеки

Правка системного промта или сценария у себя в браузере действует, пока не сменилась версия библиотеки (`library/settings.js`). Новая версия включает обновлённые системные промты и сценарии у всех. Свои сценарии и промты, созданные с нуля, обновление не трогает — их правила стоит проверить по таблице выше.

## Проверка

`node tests/run.cjs` — разбор настоящих ответов GigaChat и DeepSeek и «слабых» ответов с типичными ошибками. Ни одна строка не должна потеряться.
